# phpMyLib

**Personal library of reusable PHP helpers for databases, HTML, HTTP, XML, SOAP and ZIP.**

Include the files you need with `require_once`.

## Modules

| File | Area |
|---|---|
| `abc_0001.inc.php` | General helpers |
| `db_0001.inc.php` | Database queries (one row, N rows, HTML tables, row exists…) |
| `html_0001.inc.php` | HTML generation |
| `http_0001.inc.php` | HTTP requests and headers |
| `jsval_0005.inc.php` | Server-side counterpart of the [jsMyLib](https://github.com/manuherran/jsMyLib) validations |
| `soap_0001.inc.php` | SOAP |
| `wap_0001.inc.php` | WAP (legacy) |
| `web_0005.inc.php` | Web helpers |
| `xml_0001.inc.php` | XML |
| `zip_0001.inc.php` | ZIP files |

```php
require_once 'db_0001.inc.php';
```

Related: [jsMyLib](https://github.com/manuherran/jsMyLib) · [vbaMyLib](https://github.com/manuherran/vbaMyLib)
